# 정보 × 물리 융합수업 — 코드로 만드는 운동 시뮬레이터

> 고등학교 **정보 × 물리** 융합수업 웹앱 · 8차시 × 50분 · 2개 과정

공식을 외우는 대신 **직접 시뮬레이터를 만들어 보는** 수업입니다.
학생은 화면의 단계를 클릭하며 조작·입력·코딩·디버깅을 하고, 통과해야 다음 단계로 넘어갑니다.

**▶ 바로 열기 : https://hehuii.github.io/projectile-class/**

설치·회원가입·인터넷 연결이 필요 없습니다. 링크만 열면 바로 수업이 시작됩니다.

---

## 이 수업의 출발점

교과서는 **45°**로 던질 때 가장 멀리 간다고 합니다.
그런데 야구 홈런의 실제 발사각은 **25~30°**, 골프 드라이버는 **12~17°**입니다.

왜 다를까요? 공기저항이 있으면 `y = v₀sinθ·t − ½gt²` 가 통하지 않기 때문입니다.
손으로는 풀 수 없습니다. **하지만 컴퓨터는 풀 수 있습니다.**

시간을 아주 잘게 쪼개 조금씩 나아가는 것 — **이산화(discretization)** 하나가 8차시를 관통하는 핵심 아이디어입니다.

---

## 두 가지 과정

앱을 열면 시작 화면에서 과정을 고릅니다. 진행 기록은 과정별로 따로 저장됩니다.

### 물리 중심 과정 — 과목 「역학과 에너지」 주(主), 정보는 계산 도구

| 차시 | 주제 |
|---|---|
| 1 | 현상 관찰과 알고리즘 설계 |
| 2 | 구현과 디버깅 |
| 3 | 데이터로 최적 조건 찾기 |
| 4 | 실제로 던진 공과 비교 (실측 대조) |
| 5 | 실험에서 물리량 끌어내기 (저항계수 → 항력계수) |
| 6 | 같은 코드로 다른 운동 (단진동 · 행성 궤도 · 케플러 2법칙) |
| 7 | 에너지로 계산을 검증 (보존 · 드리프트 · 소산) |
| 8 | 나만의 탐구와 발표 |

### 정보 중심 과정 — 과목 「정보」 주(主), 물리는 문제 상황

| 차시 | 주제 |
|---|---|
| 1 | 문제 분해와 추상화 |
| 2 | 제어 구조와 자료구조 |
| 3 | 디버깅과 테스트 |
| 4 | 자료 처리 (파싱 · 통계 · 시각화) |
| 5 | 탐색 알고리즘과 복잡도 O(n) vs O(log n) |
| 6 | 최적화 (격자 · 삼분 탐색) |
| 7 | 함수와 모듈화 (고차 함수) |
| 8 | 프로젝트와 코드 리뷰 |

각 차시는 4~8단계로 나뉘며, 권장 시간의 **합계가 정확히 50분**입니다.

## 학생이 실제로 하는 일

- **조작** — 슬라이더로 궤적을 바꿔 가며 최적 발사각을 스스로 발견
- **코딩** — 빈칸을 채워 시뮬레이터를 완성 (통과 못 하면 다음 단계로 못 감)
- **디버깅** — 일부러 망가뜨린 코드 3개를 증상만 보고 원인을 찾아 수정
- **측정** — 실측 데이터와 모형을 대조하고 오차를 정량화
- **서술** — 결론을 글로 쓰고, 모든 답안이 **활동 보고서 탭에 자동 취합**되어 그대로 인쇄 제출

## 교사가 쓰는 기능

- **교사 자료 탭** — 선택한 과정에 맞춰 자동으로 바뀝니다. **16개 차시 전체**의 운영 동선(0~5·5~35·35~45·45~50분), 예상 오개념과 대응 발문 24개, 디버깅 트랙 정답, 5개 영역 루브릭, 수업 타이머, **8차시 전체 인쇄용 학생 활동지**
- **모든 단계 잠금 해제** — 진도가 늦은 학생이 많을 때 체크하면 통과 없이 건너뛰기 허용
- **교육과정 탭** — 2022 개정 총론 연계 분석, 성취기준, 성취수준 A~E, 평가기준. 성취기준↔차시 매핑을 **물리 중심·정보 중심 두 과정으로 나누어** 제시
- **[지도안 엑셀](resources/정보물리융합수업_지도안.xlsx)** — 6개 시트(차시별 지도안, 성취기준 매핑, 평가기준, 학생 평가기록 양식)

## 사용 방법

### 학생 (가장 간단)
링크를 열기만 하면 됩니다. 진행 상황과 답안은 그 PC의 브라우저에 저장되어, 창을 닫았다 열어도 이어집니다.

### 오프라인 / 학교 인터넷이 막힌 경우
`index.html` 한 파일만 내려받아 USB로 나눠 주거나 학급 클라우드에 올리면 됩니다.
외부 라이브러리를 하나도 쓰지 않아 **파일 하나로 완전히 동작**합니다.

### Windows 설치본
설치 없이 실행되는 exe와 설치 프로그램은 [Releases](../../releases)에서 받을 수 있습니다.
서명 인증서가 없어 첫 실행 시 SmartScreen 경고가 뜹니다 — "추가 정보 → 실행"으로 넘어가면 됩니다.
경고가 부담되면 위의 웹 링크나 HTML 파일을 쓰셔도 내용은 완전히 같습니다.

## 성취기준 확인 상태

**물리 — 원문 대조 완료.** 「역학과 에너지」 성취기준은 교육부 고시 2022 개정 교육과정 원문과 대조해 확인했습니다.

| 성취기준 | 내용(요지) | 차시 |
|---|---|---|
| `[12역학01-02]` | 뉴턴 운동 법칙을 이용하여 물체의 **포물선 운동**을 정량적으로 설명하고, 포물선 운동에서의 **역학적 에너지**를 구할 수 있다 | 1~4 · 7 |
| `[12역학01-01]` | 여러 가지 힘의 **합력**을 구하여 물체의 운동을 정량적으로 예측할 수 있다 | 2 · 3 · 5 |
| `[12역학03-01]` | 용수철 진자를 통해 **단진동**을 이해하고, 가속도와 변위 사이의 관계를 설명할 수 있다 | 6 |
| `[12역학01-04]` | **케플러 법칙**과 중력을 이용하여 인공위성과 행성의 운동을 분석하고 설명할 수 있다 | 6 |
| `[12역학01-05]` | **역학적 에너지 보존**을 이용하여 설명할 수 있다 | 7 |

교육과정의 **탐구 활동**에 다음이 명시되어 있어 이 수업과 직접 대응합니다.

> · 포물선 운동을 하는 물체의 **동영상을 분석**하여 역학적 에너지 보존 확인하기 → 4·7차시
> · **스마트폰을 이용**하여 다양한 놀이 기구의 운동 분석하기 → 4차시
> · **행성 관측 데이터**를 이용하여 케플러 법칙 확인하기 → 6차시

교수·학습 방향에도 *"물체의 다양한 운동을 센서, 동영상 분석, 공공 데이터 활용 등을 통해 정량적으로 분석함으로써 데이터를 활용한 탐구 활동이 이루어지도록 한다"* 고 제시되어 있습니다.

**⚠️ 정보 — 확인 필요.** 「정보」 성취기준 번호는 대조할 원문 자료가 없어 확정하지 못했습니다.
결재 문서에 넣기 전 [국가교육과정정보센터(NCIC)](https://ncic.re.kr)에서 확인해 주세요.
확신이 서지 않는 항목은 번호를 임의로 채우지 않고 **"확인 필요"로 표시**해 두었습니다.

**활동 설계 자체는 성취기준 번호와 무관하게 그대로 사용하실 수 있습니다.**
